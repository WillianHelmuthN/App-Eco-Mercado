# Manual do Usuário - Eco-Mercado

Este guia ajudará você a utilizar o aplicativo Eco-Mercado para economizar nas suas compras através da comparação de preços e gerenciamento de listas de compras.

## Instalação

1. Faça o download do aplicativo Eco-Mercado na loja de aplicativos do seu dispositivo
2. Instale e abra o aplicativo
3. Não é necessário criar conta ou fazer login - o aplicativo funciona localmente no seu dispositivo

## Tela Inicial

Ao abrir o aplicativo, você verá a tela inicial com dois botões principais:

- **Iniciar Compras**: Acessa o comparador de preços
- **Lista de Compras**: Acessa sua lista de compras

## Comparador de Preços

O comparador de preços permite comparar diferentes produtos e identificar qual oferece o melhor custo-benefício, mesmo quando estão em diferentes unidades de medida ou embalagens.

### Como usar o comparador:

1. **Selecione a unidade de medida** do produto na lista suspensa:

   - Massa: g (grama), kg (quilograma)
   - Volume: ml (mililitro), l (litro)
   - Unitário: Unidade
   - Embalagens: Caixa, Pack, Fardo

2. **Se selecionou uma embalagem** (Caixa, Pack, Fardo):

   - Informe a quantidade de unidades na embalagem
   - Informe a quantidade por unidade
   - Selecione a unidade interna da embalagem (g, ml, unidades)

3. **Informe a quantidade total** do produto

4. **Informe o valor** total do produto

5. **Clique em "Adicionar Produto"** para incluí-lo na comparação

6. **Adicione pelo menos dois produtos** seguindo os mesmos passos

7. **Clique em "Comparar Produtos"** quando tiver adicionado todos os produtos que deseja comparar

8. **Veja o resultado da comparação**:
   - O produto mais vantajoso será destacado
   - A economia percentual em relação ao produto de referência será exibida
   - Os valores unitários normalizados para uma base comum serão mostrados

### Exemplos de uso:

**Exemplo 1: Comparação de embalagens de leite**

- Produto 1: Caixa com 12 unidades de 1L cada por R$ 42,00
- Produto 2: Pack com 6 unidades de 1L cada por R$ 24,00
- Resultado: O comparador calculará o valor por litro e mostrará qual opção é mais econômica

**Exemplo 2: Comparação de pacotes de arroz**

- Produto 1: 5kg por R$ 24,50
- Produto 2: 1kg por R$ 5,20
- Resultado: O comparador mostrará o valor por kg e indicará a melhor opção

## Lista de Compras

A lista de compras permite organizar os itens que você precisa comprar.

### Como usar a lista de compras:

1. **Adicionar item**:

   - Digite o nome do produto no campo "Nome do produto"
   - Informe a quantidade no campo "Quantidade" (opcional)
   - Clique em "Adicionar"

2. **Visualizar itens**:

   - Todos os itens adicionados aparecerão na lista abaixo
   - Cada item mostrará o nome e a quantidade

3. **Remover item**:
   - Clique no botão "✕" ao lado do item que deseja remover
   - Confirme a remoção

### Observações:

- A lista de compras é salva automaticamente no seu dispositivo
- Os itens permanecerão na lista mesmo se você fechar o aplicativo
- Você pode adicionar quantos itens desejar

## Dicas para Economizar

- Use o comparador de preços para identificar as melhores ofertas
- Compare produtos de diferentes marcas usando a mesma base de cálculo
- Crie sua lista de compras antes de ir ao mercado para evitar compras por impulso
- Verifique os preços de produtos em diferentes embalagens (grande, médio, pequeno)
- Lembre-se que nem sempre a embalagem maior é a mais econômica

## Solução de Problemas

**Problema**: O aplicativo não está salvando minha lista de compras
**Solução**: Verifique se você possui espaço disponível no dispositivo

**Problema**: Não consigo adicionar um produto para comparação
**Solução**: Certifique-se de informar a quantidade e o valor do produto

**Problema**: Os valores de comparação parecem incorretos
**Solução**: Verifique se selecionou as unidades de medida corretas e informou os valores corretamente
